Bins (Online vs Local)

If you’re on the public URL (qr.<domain>), the Bin Manager usually lives at bins.<domain>. If you’re on the LAN (no ports), bins usually live under /bins. This UI auto-adjusts the Bins link.

Login / Permissions

Some actions require shop or admin. Use /login to authenticate when prompted.

Barcode Mapping (Operators + Stations)

Operator badges: Go to Admin → Operator Badge Barcodes. Scan (or paste) the badge barcode into Badge Barcode and set the Operator ID. After saving, scanning that badge will “log in” the operator for the day.

Stations: Go to Admin → USB Dongle Mapping. This maps each scanner device to a station code + display name (what shows up in reports).

Label variations (CSV field mapping): Go to Admin → USB Dongle Mapping → Barcode mapping…. Paste a raw scan, click Split, map columns (Job/Cabinet/Part/etc), then Save. This helps when different label formats use different delimiters or column order.

Label Printing Agent

For one-click printing without browser dialogs, you need the **Innosaw Agent**.

📥 Download Innosaw Agent (Windows ZIP)
Prefer ZIP (one-folder). It avoids Windows blocking one-file EXEs and you can extract it anywhere. Download EXE (legacy)

Setup Instructions:

  1. Download the ZIP and extract it somewhere permanent (recommended: C:\Innosaw\Agent\).
  2. Run InnosawAgent.exe from that folder.
  3. If it's the first time, a Settings window will appear.
  4. Paste your Agent Token (get this from Admin → Stations → Label Printing).
  5. Select your Printer from the dropdown list.
  6. Click Save & Start. The app will move to your system tray (near the clock).

* Tip: Use the "Create Desktop Shortcut" button in Settings for easy access.

Reports & Mozaik

The Reports page includes Mozaik tools. Upload .mkzlbl files under the Mozaik tab to enable expected-vs-scanned and scan enrichment.

How to export from Mozaik:

  1. In Mozaik Optimizer, finalize optimization and create G-codes.
  2. Go to File → Export → Export to Label App...
  3. Ensure you have a Device ID setup that can print labels.
  4. Check the Labels box for that device.
  5. Naming Tip: Use "Job Name + Run #" for the Label Run Name.
  6. Once exported, upload the .mkzlbl file to the Dashboard.

Tooling Page

The Tools page manages your tool inventory and tracks tool usage across machines.

Main Features:

  • Tool Inventory: View all tools grouped by type (Drills, Router, Edge, Other) or custom groups. Edit tool names, quantities, expected life, and assigned machines.
  • Tool Block Editor: In the "Tooling Layout" tab, visually draw and edit drill block configurations for each machine. Select cells, assign tools, and flip sides (L/R).
  • Machine Setup: See which tools are currently installed in each machine slot, with tool life tracking. Update quantities and tool assignments per slot.
  • Tool Change Logging: Log when tools are changed on machines. Track parts/sheets processed since the last change.
  • Bulk Operations: Select multiple tools and log changes for all of them at once.

Tracking: Tools track usage in parts or sheets (for CNC machines). Counts reset when you log a tool change. You can filter by machine to see tool-specific usage.

Inventory Page

The Inventory page tracks materials and stock levels across your shop.

Main Features:

  • Material Tracking: Track materials between all machines. View quantity, category, thickness, status, location, and last consumed date.
  • Parts & Sheets Tracking: Track usage for both parts and sheets. Filter by materials or part types to narrow down tracking.
  • Bulk Actions: Select multiple materials and perform bulk operations (Receive, Consume, Edit, Delete) using the sticky action bar at the top.
  • Quick Edit: Click on quantity to edit inline. Click on material name to expand details (supplier, SKU, order URL, notes).
  • Column Management: Drag column headers to reorder. Drag the resize handle (right edge) to adjust column widths.

Filtering: Use the search bar and category filters to quickly find materials. Selected rows are highlighted for easy identification.

Maintenance Page

The Maintenance page provides full tracking of machine downtime, maintenance events, and issues.

Main Features:

  • Downtime Tracking: Log downtime events with start/end times. System automatically calculates duration and parts processed since last maintenance.
  • Event Types: Categorize events (maintenance, breakdown, calibration, etc.). Search and filter by machine or event type.
  • Editable Descriptions: Edit event descriptions after creation. Add photos, notes, and assign to team members.
  • Inventory Metrics: View inventory metrics at the top of the page for quick reference.
  • Tool Change History: See complete history of tool changes across all machines with parts/sheets processed.
  • Machine Setup View: Quickly see what tools are currently in each machine and their tool life status.

Search: Use the search bar to find events by machine, event type, tool, or description. Filter by resolved/unresolved status.

🔔 Push Notifications Setup

Get instant notifications for chat messages, board updates, and more on desktop and mobile.

Recommended Browsers:

  • Desktop: Chrome, Edge, or Firefox (Safari has limited support)
  • Android: Chrome or Edge
  • iPhone/iPad: Safari (requires Add to Home Screen - see below)

Desktop Setup:

  1. Go to Notifications page
  2. Click "Enable Push Notifications"
  3. When browser asks, click "Allow"
  4. Click "Send Test Notification" to verify

Android Setup:

  1. Open site in Chrome or Edge
  2. Tap the menu (⋮) → "Add to Home screen" or "Install app"
  3. Open the app from your home screen
  4. Go to Notifications → "Enable Push Notifications"
  5. Allow notifications when prompted

iPhone/iPad Setup:

  1. Open site in Safari (required for iOS)
  2. Tap the Share button (box with arrow)
  3. Scroll down and tap "Add to Home Screen"
  4. Tap "Add" in the top right
  5. Open the app from your home screen
  6. Go to Notifications → "Enable Push Notifications"
⚠️ Important: On iOS, push notifications ONLY work when the app is installed to your home screen. They won't work in the regular Safari browser.

Troubleshooting:

  • Not receiving notifications? Check your device's notification settings for the browser/app
  • "Enable" button not working? Try clearing site data and re-enabling
  • Test notification fails? Try disabling and re-enabling notifications
