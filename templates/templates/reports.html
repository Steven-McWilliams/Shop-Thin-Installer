Custom Reports — Help & Examples
Tip: you can drag this window by the header, and resize it from the bottom-right corner. We remember its size/position on this browser.

Core ideas

Aggregate Cycles (timer) Stations scope Buckets
Type
Aggregate = group scans and calculate totals (count, linear feet, etc).
Cycles (timer) = build timers using scans (start/stop), per key (cabinet/sheet/part).
Stations (optional)
Comma-separated station codes to include (e.g. Sand). Leave blank = all stations.
Cycle key (timer)
Cabinet uses cabinet_assembly (fallback cabinet_name).
Sheet uses gcode.
Part uses part_num (fallback part_name).
Split gap (min)
If a pause between scans for the same key exceeds this gap, the timer closes and a new timer starts.
Close after N scans
0 = keep the timer open until key changes or gap split closes it.
2 = classic start/stop: 1st scan starts, 2nd scan stops (great for sanding per-part).
Timer output
Cycles = one row per timer (start/end/duration/sqft).
Summary = totals grouped by your “Group by” selection (and optional bucket).
Bucket
Optional grouping by day/week/month (uses shop-local time).

Formulas (Cycles timer)

Duration
duration_seconds = end_time - start_time
Square feet (sqft)
We compute sqft from part size (if present):
sqft = (length_in × width_in) / 144
Length/width accept inches or mm (best-effort conversion).
Seconds per sqft (summary)
seconds_per_sqft = duration_seconds / sqft (only if sqft > 0)

Example 1 — Sanding per part (start/stop)

Goal: Each part gets a timer: scan once to start, scan again to stop. Only count station Sand.
Result shows Duration, SQFT of the part, and Start/End times.
Tip: If your station is named something else (e.g. "S1"), change "Sand" below to your code.
{
  "kind": "cycles",
  "station_codes": ["Sand"],
  "key_fields": ["part_num","part_name","cabinet_assembly"],
  "key_mode": "first_nonempty",
  "close_on_n_scans": 2,
  "split_on_gap_minutes": 0,
  "output": "cycles",
  "time_bucket": "none"
}

Example 2 — Sanding labor summary by day + job

Goal: Daily totals for Sanding: total parts, total SQFT, and total time spent.
{
  "kind": "cycles",
  "station_codes": ["Sand"],
  "key_fields": ["part_num","part_name","cabinet_assembly"],
  "key_mode": "first_nonempty",
  "close_on_n_scans": 2,
  "output": "summary",
  "time_bucket": "day",
  "group_by": ["job_name"]
}
In the builder: set Group by = Job, Timer output = Summary, Bucket = Day.

Example 3 — Edge band usage (aggregate)

Goal: Totals of edge-band usage by edge prefix + band index.
{
  "kind": "aggregate",
  "group_by": ["edge_prefix","band_index"],
  "filters": [{"field":"edge_material","op":"exists"}],
  "metrics": [
    {"key":"parts","op":"count_distinct_part"},
    {"key":"linear_feet","op":"sum_edge_lf"}
  ],
  "dedupe": true,
  "exclude_band_indexes": [6]
}
IP note: these examples show how the builder works; you can keep your more advanced production heuristics in station settings or private templates if you want.
